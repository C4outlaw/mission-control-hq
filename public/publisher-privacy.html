Myrie Publisher

Privacy policy

Effective October 18, 2026. This policy describes Myrie Publisher, the private local publishing application operated by MyrieHQ. Contact: myriework@gmail.com.

Information accessed

When you authorize a platform, the application accesses account or channel identifiers, display names, authorization tokens, and publishing status needed to connect the intended destination. For YouTube, it requests read-only and upload permissions to verify the channel, upload your selected videos and retrieve their status. It processes media files, captions, titles, schedules, audience choices and publication receipts that you provide or approve. It does not request your platform password.

Use and disclosure

Data is used to provide requested publishing functions, prevent posting to the wrong channel, check upload results and display receipts. Approved media and post metadata are sent to the selected platform. Platform APIs receive authentication credentials needed to authorize those requests. When Instagram requires a downloadable source, a temporary single-file HTTPS delivery link is used for the selected media; the delivery provider processes that traffic. Existing browser sessions are used for browser-based workflows such as TikTok Studio.

Myrie Publisher does not sell Google user data, use it for advertising, or use it to train AI models. Access is limited to the operator and authorized managers for the publishing workflow. Myrie Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and protection

Imported media, schedules, destination records and receipts are stored on the operator's Windows computer. API credentials are encrypted with Windows Data Protection API for the current Windows user. This protects stored credentials but does not replace computer access controls. Local backups made by the operator may contain copies. The public information website does not host the local publishing database or vault.

Retention, revocation and deletion

Local media and job records remain until the operator removes them. You can revoke Google authorization through Google account permissions. Revocation prevents further authorized API access; it does not delete videos already uploaded to YouTube. Delete published videos through the relevant platform.

To request removal of locally stored account data and tokens, contact myriework@gmail.com with the channel name or ID. Do not send passwords or tokens. The operator will verify the request, stop pending jobs for that destination and remove its locally stored API data and credentials within seven days. Media you independently supplied is handled according to your deletion request. Backups under the operator's control must also be addressed. The application has no automatic deletion timer for ordinary local media.

Third-party services

Myrie Publisher uses YouTube API Services. See the Google Privacy Policy and YouTube Terms of Service. Other connected platforms and any temporary media delivery provider process data under their respective policies. This informational website's host also processes ordinary web requests.

Changes and contact

Changes to this policy will be dated on this page. Questions and account data requests can be sent to myriework@gmail.com.
